# PriceTrack — MongoDB Database Backup & Restoration Manual

This archive contains an exact, binary BSON export (`mongodump`) of the complete **PriceTrack** production database. All ObjectIds, BSON data types (including native ISODate instances, 64-bit integers, doubles, and boolean values), embedded subdocuments, arrays, unique constraints, and compound indexes have been preserved with 100% fidelity.

## 2. Prerequisites for Restoring

To restore this backup to any local MongoDB instance or MongoDB Atlas cluster, ensure that **MongoDB Database Tools** (`mongorestore`) is installed.

* **MongoDB Database Tools Download:** [https://www.mongodb.com/try/download/database-tools](https://www.mongodb.com/try/download/database-tools)
* Verify installation in your terminal:
  ```bash
  mongorestore --version
  ```

---

## 3. How to Restore the Backup

### Option A: Restore to MongoDB Atlas (Cloud Cluster)

Run the following command in the directory containing the `pricetrack` backup folder:

```bash
mongorestore --uri="<YOUR_MONGODB_ATLAS_URI>" --nsInclude="<TARGET_DATABASE_NAME>.*" ./pricetrack
```

*Replace `<YOUR_MONGODB_ATLAS_URI>` with your actual connection string (e.g., `mongodb+srv://<username>:<password>@cluster0.example.mongodb.net/`).*  
*Replace `<TARGET_DATABASE_NAME>` with your desired database name (e.g., `pricetrack`).*

> [!NOTE]
> If your MongoDB password contains special characters (such as `@`, `:`, `/`, or `%`), URL-encode them (for example, `@` becomes `%40`).

---

### Option B: Restore to a Local MongoDB Instance

To restore to a local MongoDB instance running on `localhost:27017`:

```bash
mongorestore --uri="mongodb://127.0.0.1:27017" --nsInclude="pricetrack.*" ./pricetrack
```

---

### Option C: Restore into a Differently Named Database

If you wish to restore the data into a database with a different name (e.g., `pricetrack_prod`):

```bash
mongorestore --uri="<YOUR_MONGODB_URI>" --nsFrom="pricetrack.*" --nsTo="pricetrack_prod.*" ./pricetrack
```

## 4. How to Verify the Restored Data

After restoring, you can verify collection counts using `mongosh` or MongoDB Compass:

```javascript
// Connect to your database in mongosh
use pricetrack;

// Check document counts
db.products.countDocuments();       // Expected: 57
db.storeListings.countDocuments();  // Expected: 240
db.priceHistory.countDocuments();   // Expected: 7447
db.stores.countDocuments();         // Expected: 5
db.users.countDocuments();          // Expected: 2
db.watchlists.countDocuments();      // Expected: 1
db.priceAlerts.countDocuments();    // Expected: 1
db.sessions.countDocuments();       // Expected: 34
db.notifications.countDocuments();  // Expected: 1

// Verify text search index on products
db.products.find({ $text: { $search: "iPhone" } }).count();
```
